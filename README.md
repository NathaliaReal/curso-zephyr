# Zephyr desde Cero

Curso interactivo para el equipo QA: qué es Zephyr, cómo crear casos de prueba, cómo importarlos desde CSV (incluido el CSV del Agente de Gobernanza QA), cómo ejecutarlos en ciclos y cómo funciona la trazabilidad.

- `index.html`: el curso. Se abre en cualquier navegador.
- `plantilla-casos-zephyr.csv`: plantilla para importar casos a Zephyr desde un Excel propio.

Elaborado por Nathalia Real - QA Tech Leader.
