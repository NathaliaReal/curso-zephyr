# Zephyr desde Cero

Curso interactivo para el equipo QA sobre cómo trabajar en Zephyr: cargar los casos de prueba (escribiéndolos o importándolos desde CSV, incluido el del Agente de Gobernanza QA), ejecutarlos en ciclos, cambiar su estado, adjuntar evidencia y hacer seguimiento con trazabilidad en Jira.

- `index.html`: el curso. Se abre en cualquier navegador.
- `plantilla-casos-zephyr.csv`: plantilla para importar casos a Zephyr desde un Excel propio.

Elaborado por Nathalia Real - QA Tech Leader.
